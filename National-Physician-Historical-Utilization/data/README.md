# Data

The source workbook is not stored in this repository. Download it from CIHI:

1. Go to the [National Physician Database metadata page](https://www.cihi.ca/en/national-physician-database-metadata).
2. Download the **NPDB data table release (ZIP)**.
3. Open **National Physician Database Historical Utilization, 2015–2016 to 2024–2025 — Data Tables (XLSX)**.

Tables used:

| Table | Contents |
| --- | --- |
| Table 1 | Head count, number of services, payments, cost per service and services per 100K by fiscal year, jurisdiction, specialty and National Grouping System (NGS) category (204,648 rows) |
| Table 3 | Statistics Canada net population estimates by province/territory, 2015–2024 |

Citation: Canadian Institute for Health Information. *National Physician Database Historical Utilization, 2015–2016 to 2024–2025 — Data Tables.* Ottawa, ON: CIHI.
