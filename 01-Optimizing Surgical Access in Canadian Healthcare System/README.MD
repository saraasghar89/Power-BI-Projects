# Power BI Projects

Power BI dashboards analyzing Canadian healthcare data from the Canadian Institute for Health Information (CIHI).

| Project | Description |
| --- | --- |
| [Physician Service Utilization in Canada, 2015–2016 to 2024–2025](National-Physician-Historical-Utilization/) | Ten years of national physician billing data: how services track population growth, the shift from consultations to procedures and from family medicine to specialists, and where regional access is weakest. |
| [Optimizing Surgical Access in Canada's Healthcare System](Optimizing-Surgical-Access-Canada/) | Wait times for priority procedures, 2008–2024: benchmark performance by province, MRI backlogs, COVID-19's effect on hip replacements, volume vs wait time, and where a federal grant would help most. |
